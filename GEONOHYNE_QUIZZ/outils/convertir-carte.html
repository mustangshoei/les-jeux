Convertir une carte

Transforme un fichier GeoJSON (pays, régions, départements, provinces…) en carte utilisable par GéoNohyne Quizz. Tout se passe dans votre navigateur : aucun fichier n'est envoyé nulle part.

2. Aperçu

Ensuite
  1. Placez le fichier téléchargé dans le sous-dossier de data/ qui convient (data/france/, data/monde/…).
  2. Dans index.html, ajoutez sous « Cartes » la ligne <script src="data/monde/carte-identifiant.js"></script> (avec le bon sous-dossier).
  3. Dans un fichier de quiz (copie de js/france/quiz-departements.js), indiquez carte: 'identifiant', ajoutez la ligne <script> de ce quiz dans index.html et sa carte { quiz: '…' } dans js/menu.js.
